# Simple Linear Regression
A Python implementation of Simple Linear Regression using Scikit-learn for prediction and data visualization.

## Technologies Used
* Python
* Scikit-learn
* Pandas
* NumPy
* Matplotlib
* Google Colab

## Workflow
1. Dataset Loading
2. Data Preparation
3. Feature and Target Selection
4. Model Training
5. Prediction
6. Model Evaluation
7. Data Visualization

## Dataset
A suitable dataset is used to demonstrate the relationship between an independent variable and a dependent variable.

## Purpose
This repository demonstrates Simple Linear Regression for understanding relationships between variables, generating predictions, and visualizing the regression line.
